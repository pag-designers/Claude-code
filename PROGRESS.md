## CP3 — what was built (BRIEF §5, ADR-019)

- **Project model:** one serialisable `Project` JSON (`shared/editor.ts`): tracks (video/audio/text/subtitles/overlay/music), items (video, audio, image, text, shape, subtitle cue), keyframes + easing (incl. bezier), speed/ramp/reverse/freeze, transitions-as-overlaps, fades, colour/LUT/filters, blend modes, blur, mirror/rotate, crop keyframes (reframe), markers, groups. Optimistic `rev` saves (CONFLICT banner), autosave 5 s, version history (auto ≤ 1/5 min, keep 40; manual; restore), backup of the project JSON to storage.
- **One evaluator for preview and export** (`shared/editor-eval.ts`): easing, keyframes, source-time maths, transitions, fades, ducking envelope, colour maths, text animation, natural layout. The WebGL2 compositor and the FFmpeg exporter both call it; neither re-implements semantics.
- **Editor UI** (`/editor/?id=`): resizable shell, media bin (project media + Library clips/videos + import of video/audio/image/LUT), WebGL2 preview with on-canvas handles (move/scale/rotate/crop/snap), transport (J/K/L, frame step, loop, speed), multi-track timeline (waveforms, thumbnails, snapping with guides, ripple, razor, marquee, groups, markers, lock/hide/mute, zoom to fit, context menus, shortcuts overlay `?`), full inspector (transform, keyframes with graph editor, speed, audio/fades/gate/beats + cut-to-beats, transition grid, colour/filters/LUT, fit/crop/blend, reframe, text + animation + brand chip, shapes, subtitle words/style/AI re-sync, track gain/ducking), history (command pattern, one undo step per gesture), versions panel, export panel (presets, resolution/fps/bitrate, range, SRT/VTT sidecars).
- **Open from Library:** a clip becomes a project (face-tracked crop path from the proxy as crop keyframes, subtitle cues as editable items, hook card as text) or a blank/video project; Library → **Edited** and **Exported** tabs (rename/duplicate/delete, play, download, delete).
- **Export** = durable queue job (`editor.export`), full-resolution source re-obtained via `ensureSource`, graph written to a filter script, H.264/AAC, loudness-normalised, poster, SRT/VTT, uploaded to storage; progress events; cancel.
- **Plumbing:** migration 0004 (EditorProject, EditorVersion, EditorExport; non-destructive, upgrade-tested), 19 editor + 4 export IPC channels + `editor:export` event, `EditorService`, `electron/main/services/editor-export/**` (README documents every rule → FFmpeg construct and measured error), `editor-media/**` (waveform, beats, thumbnail strip, preview copies), CORS header injection for presigned URLs (WebGL/WebAudio), unload guard ("Stay / Leave anyway").
- **Not built (by design):** Pixabay music — no official API, so the Music tab explains it and offers file import (disabled, no fake catalogue).

## CP3 — NOT verified / known issues

- **Audio was never listened to.** Loudness, ducking, fades and transition crossfades are checked by signal/graph tests only.
- **60 fps on a real GPU is unmeasured.** SwiftShader (software GL) gives ≈ 40 ms/frame for 4 layers at 540×960 (≈ 20+ fps); the engine itself costs ≈ 0 and uploads are cached.
- H.264 preview inside Playwright's Chromium is untested (it lacks the codec); the real Electron e2e plays the real H.264 proxy. Hardware encoders, macOS and Windows not run.
- Known preview/export deviations (documented in the exporter README): dip veil is full-canvas, group blend is per layer, contain/native with an animated crop size is frozen at the first frame, arrow stroke is approximated.
- OS file drop onto the timeline is unsupported (toast points to Import); dragging several clips into the "new track" zone is unsupported; 3-tile video-call split can render a black tile (CP2 issue).
- Thumbnail candidates still contain burned-in captions (CP2).
- An orphaned 84-minute ffmpeg process was seen once during exporter development (reverse/trim inputs); not reproduced, export has a cancel path but no watchdog timeout yet.
- Real Claude quality still unverified (no API key in this environment).

## CP2 — what was built

- **Captions:** 14 data-driven presets (`CaptionStyle`: font, case, fill, stroke, shadow, box, active-word highlight, keyword colour, animation, layout, chunking) rendered by libass; Style Studio dialog with a gallery, every field editable, custom presets (save/duplicate/delete), preview = real libass render (≈100–250 ms). Clean Pop output is byte-identical to CP1 (48/48 documents). Fonts shipped: Montserrat, Anton, Bebas Neue, Poppins, DM Serif Display, IBM Plex Mono (OFL).
- **Subtitles:** edits layered over the ASR transcript (text / shift / hidden words, breaks, merges), server-assigned revision, "captions outdated" per clip, inline editing UI (virtualised, undo/redo, split/merge/retime/search), SRT/VTT export (video or clip range).
- **Reframe:** modes auto / follow one face / split two people / screen + face / centre; layout detection from real frames; letterbox crop; gentle zoom; per-clip mode with re-render.
- **Steering:** `moments:find` free-text re-run over the cached transcript (durable job, tagged with run + prompt, de-duplicated, best N rendered); analysis-only mode (summary/transcript without ranking or rendering).
- **One-Click Highlights:** LLM picks 3–5 beats in story order, code aligns them to words, segments rendered separately and stitched (cut / crossfade / dip / slide / zoom), loudness normalised once.
- **Hooks / metadata / thumbnails:** 5 hook variants per platform (apply = burn as title card, re-render; remove card), per-platform title/description/hashtags/posting time (labelled general advice), thumbnail candidates scored (sharpness, face, composition via the sidecar) + vision-model rank + overlay text; posters are caption-free (re-rendered from the source).
- **AI Chat:** context-aware, streams over `chat:event`, `[mm:ss]` citations, tool calls executed by the same services as the UI (`create_clip`, `add_marker`, `write_metadata`, `rewrite_hook`, `find_moments`), persisted threads, markers on the player timeline.
- **Tools hub:** 8 live tool routes (find moments, highlights, summary, transcripts, subtitles, reframe, thumbnail, hook) + LATER cards disabled with the tooltip.
- **Plumbing:** migration 0003 (non-destructive, upgrade-tested), 37 new IPC channels + 3 events, `Cp2Service`, `ChatService`, `StyleRegistry`, sidecar `/frames/score` and small-face detection.

## CP1 — what was built

- **Pipeline** (`electron/main/pipeline/`): durable-queue job per video + one per clip render. Stages: ingest → prepare (audio, 480p proxy, shot detection) → transcribe + moments (10-min windows, ranked while the next window transcribes, strong clips render immediately) → understand (overview, chapters, notes, topics) → select (top N / ≥ minScore) → render → finalize (upload proxy, free local disk). Resumes after restart; per-stage retry; cancel; cross-run transcript cache in object storage; clips ≥ 72 start rendering as soon as they are found.
- **Services:** yt-dlp ingest with client fallback + actionable bot-check error; ffmpeg media; audio signals (loudness, speech rate, silences, laughter/applause, speaker changes) + sentence segmentation; Claude layer (structured outputs, sentence-id spans, prompt caching, budget guard, cost recording, repair retry); multi-signal candidate generator + word-boundary snapping; face-tracked smooth crop path (EMA/dead-zone, cut-aware); "Clean Pop" ASS captions (word-level, active-word pop, safe area, Montserrat ExtraBold shipped) + hook title card + SRT/VTT; FFmpeg render (sendcmd crop pan, burn captions, −14 LUFS two-step loudnorm, hardware-encoder probe by test encode, 1080×1920 H.264/AAC).
- **UI:** real Home flow (URL validation, probe preview with CC badge, options, readiness blockers), live pipeline view (7 stages, ETA, log, retry/cancel), Library (Videos / Clips / Favorites; filters, sort, grid/list, hover preview, multi-select, bulk download/favorite/delete), video detail (Overview / Transcript with search + seek / Chapters / Clips / Notes), clip drawer (player, score breakdown bars, source jump, download/re-render), live AI-cost chip.
- **IPC:** 17 new channels + 3 events (see `shared/ipc.ts`); schema migration 0002 (non-destructive ADD COLUMNs).

### Bugs found by running it for real (all fixed, with regression tests)

1. Sidecar HTTP client died on any request > 5 s (Node's default agent idle timeout) — real transcription could never finish. Dedicated agent; test fails without the fix.
2. `pipeline:start` options patch re-applied zod defaults (same class as the CP0 settings bug) → `pipelineOptionsPatchSchema`.
3. `settings:set`/`secrets:*` refreshed the storage provider fire-and-forget → an immediate Start saw stale state; handlers now await it.
4. Orchestrator hinted candidates from the overlap context region (belonging to the previous window) → wasted ranking slots; now only the new region, +2 spare picks on later windows. Skip reasons are logged.
5. Cost: Haiku 5.5 long-prompt tier (> 100K tokens bills 5×) added to pricing.
